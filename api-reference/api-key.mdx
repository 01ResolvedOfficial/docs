## GET /v1/api-key/current

Returns information about the API key making the current request.

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/api-key/current"
```

<Accordion title="Example Response">
```json
{
  "data": {
    "id": 17,
    "name": "Partner API Key",
    "description": "Dashboard integration",
    "type": "partner",
    "status": "active",
    "isActive": true,
    "keyPrefix": "01r_ab12cd34",
    "planTierId": 2,
    "overagePolicy": "hard_stop",
    "usageAlertThreshold": 80,
    "allowanceResetsAt": null,
    "expiresAt": "2026-12-31T23:59:59.000Z",
    "lastUsedAt": "2026-10-16T05:41:22.000Z",
    "revokedAt": null,
    "createdAt": "2026-09-27T02:13:00.532Z",
    "updatedAt": "2026-10-16T05:41:22.000Z"
  }
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `name` / `description` | Label and note set when the key was issued |
| `type` | Key type, e.g. `partner` |
| `status` / `isActive` | Whether the key is currently valid. A revoked key has `revokedAt` set |
| `keyPrefix` | The first characters of the key, for identifying it without exposing the full key |
| `expiresAt` | Expiry timestamp, or `null` if the key does not expire |
| `lastUsedAt` | When the key last made a request |
| `planTierId`, `overagePolicy`, `usageAlertThreshold`, `allowanceResetsAt` | Your plan and usage allowance |
