These endpoints return data aggregated across **all** ownership coin projects on 01Resolved. No parameters are required unless noted.

---

## GET /v1/global-dashboard/overview/ownership-coins/market-cap-chart

Returns the combined market cap of all ownership coin projects with hourly historical chart data.

**Parameters:** none

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/global-dashboard/overview/ownership-coins/market-cap-chart"
```

<Accordion title="Example Response">
```json
{
  "data": {
    "marketCapValue": "102638651.52",
    "marketCapValueLast24h": "112256306.05",
    "marketCapChangePercentage24h": "-8.41",
    "chart": [
      { "timestamp": "2026-06-03T10:00:00.000Z", "value": "112256306.05" },
      { "timestamp": "2026-06-03T11:00:00.000Z", "value": "112786961.46" }
    ]
  }
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `marketCapValue` | Current combined market cap in USD across all ownership coin projects |
| `marketCapValueLast24h` | Combined market cap 24 hours ago |
| `marketCapChangePercentage24h` | 24h percentage change in combined market cap |
| `chart[].timestamp` | UTC timestamp for this hourly data point |
| `chart[].value` | Combined market cap at this timestamp |

## GET /v1/global-dashboard/projects-launch

Returns all ownership coin projects with full token metrics, treasury data, and launch state. The richest per-project summary available from a single endpoint.

**Parameters:** `limit`, `page`

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/global-dashboard/projects-launch?limit=10"
```

<Accordion title="Example Response">
```json
{
  "meta": { "totalItems": 12 },
  "data": [
    {
      "organizationSlug": "metadao",
      "organizationName": "MetaDAO",
      "launchState": "Complete",
      "tokenSymbol": "META",
      "tokenUsdPrice": "3.0282",
      "tokenPriceChangePercentage24h": "-10.45",
      "tokenPriceChangePercentage7d": "3.48",
      "tokenCirculatingSupply": "22684697.68",
      "tokenTotalSupply": "22684697.68",
      "marketCap": "68692867.06",
      "fdv": "68692867.06",
      "treasuryValue": 11983785.31,
      "spendingLimit": 240000,
      "proposalCount": 37,
      "netAssetValue": 0.5363,
      "monthsOfRunway": 42.14,
      "mNAV": 5.73,
      "premDisc": 4.65
    }
  ]
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `launchState` | ICO state: `Complete`, `Live`, etc. |
| `marketCap` | Current market cap in USD. Formula: `tokenUsdPrice × circulatingSupply` |
| `fdv` | Fully diluted valuation in USD. Formula: `tokenUsdPrice × totalSupply` |
| `netAssetValue` | NAV per Adjusted Supply (NAV/AS). Formula: `(Treasury Stables + LP Value (non-native side) + Other Non-Native Holdings) ÷ (Total Supply − Protocol-Controlled Tokens − Unvested Allocations)`. If NAV/AS > spot price, the project is trading at a relative discount. If NAV/AS < spot price, it is trading at a relative premium. |
| `monthsOfRunway` | Months of runway at current spend rate |
| `mNAV` | Fully Diluted Market Cap ÷ Net Asset Value. Indicates whether the token trades at a premium or discount to its non-native asset backing |
| `premDisc` | Spot Premium / Discount to NAV (%). Formula: `(Spot Price − NAV/AS) ÷ NAV/AS`. Positive = trading above NAV/AS (premium). Negative = trading below (discount). |

## GET /v1/global-dashboard/recent-launches

Returns all ICOs currently live or recently launched, with full raise and token details.

**Parameters:** `limit`, `page`

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/global-dashboard/recent-launches?limit=10"
```

<Accordion title="Example Response">
```json
{
  "meta": { "totalItems": 68 },
  "data": [
    {
      "launchAddr": "9qEQo5P6kwcWg1YhyPB5CEX6MAzufsT3a25HuxQg7WhC",
      "baseMint": "DwCBrWrAGokHmysLL2XbY7TCZpbRH9QUAZxHnyWxmeta",
      "title": "GeSIM",
      "subDescription": "GeSIM is the privacy layer for on-chain lives.",
      "organizationSlug": "gesim",
      "tokenSymbol": "GSIM",
      "state": "Live",
      "minimumRaiseAmount": "28000000000",
      "committedAmount": "70562000000",
      "fundsAccepted": null,
      "unixTimestampStarted": "1780437612",
      "secondsForLaunch": "604800",
      "isFeatured": false,
      "isPermissionLess": true,
      "tokenUsdPrice": "0",
      "icoReturn": 0,
      "fdv": null
    }
  ]
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `launchAddr` | Onchain address of the ICO launch program |
| `state` | Launch state: `Live`, `Complete`, etc. |
| `minimumRaiseAmount` | Minimum raise target in raw USDC units. Divide by `10^6` for USDC value |
| `committedAmount` | Total USDC committed by contributors. Divide by `10^6` |
| `fundsAccepted` | Total USDC accepted (null if raise not yet closed) |
| `secondsForLaunch` | Duration of the ICO raise window in seconds (604800 = 7 days) |
| `isPermissionLess` | Whether any wallet can contribute without whitelisting |
| `icoReturn` | Return multiple relative to ICO price since launch |

## GET /v1/global-dashboard/search

Returns matching projects and proposals from a global search query.

**Parameters:** `search` (required)

<Warning>
  The parameter is `search=`. Using `q=`, `query=`, or `term=` returns a 400 error.
</Warning>

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/global-dashboard/search?search=meta"
```

<Accordion title="Example Response">
```json
{
  "meta": { "totalItems": 15 },
  "data": {
    "projects": [
      {
        "slug": "metadao",
        "name": "MetaDAO",
        "imageUrl": "https://imagedelivery.net/...",
        "symbol": "META"
      }
    ],
    "proposals": [
      {
        "publicKey": "G33HJH2J2zRqqcHZKMggkQurvqe1cmaDtfBz3hgmuuAg",
        "title": "Meta-PoW: The ORE Treasury Protocol",
        "slug": "coal"
      }
    ]
  }
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `data.projects` | Matching ownership coin projects |
| `data.proposals` | Matching proposals across all projects |
| `projects[].slug` | Use with [Project](/api-reference/project/overview) endpoints for detailed data |
| `proposals[].publicKey` | Use with [Project > Decision Markets](/api-reference/project/proposals) endpoints for market data |
