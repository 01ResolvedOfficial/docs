These endpoints match the **Ownership Coin ICOs** and **Ownership Coins by Funding** views on 01Resolved: launches that are live or just finished, completed raises, and the graveyard of projects that were liquidated or wound down. No parameters are required unless noted. For one project's ICO in detail, including every contributing wallet, see [Project > Overview > ICO](/api-reference/project/ico).

---

## GET /v1/global-dashboard/recent-launches

Returns all ICOs currently live or recently launched, with full raise and token details.

**Parameters:** `limit`, `page`

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/global-dashboard/recent-launches?limit=10"
```

<Accordion title="Example Response">
```json
{
  "meta": { "totalItems": 68 },
  "data": [
    {
      "launchAddr": "9qEQo5P6kwcWg1YhyPB5CEX6MAzufsT3a25HuxQg7WhC",
      "baseMint": "DwCBrWrAGokHmysLL2XbY7TCZpbRH9QUAZxHnyWxmeta",
      "title": "GeSIM",
      "subDescription": "GeSIM is the privacy layer for on-chain lives.",
      "organizationSlug": "gesim",
      "tokenSymbol": "GSIM",
      "state": "Live",
      "minimumRaiseAmount": "28000000000",
      "committedAmount": "70562000000",
      "fundsAccepted": null,
      "unixTimestampStarted": "1780437612",
      "secondsForLaunch": "604800",
      "isFeatured": false,
      "isPermissionLess": true,
      "tokenUsdPrice": "0",
      "icoReturn": 0,
      "fdv": null
    }
  ]
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `launchAddr` | Onchain address of the ICO launch program |
| `state` | Launch state: `Live`, `Complete`, etc. |
| `minimumRaiseAmount` | Minimum raise target in raw USDC units. Divide by `10^6` for USDC value |
| `committedAmount` | Total USDC committed by contributors. Divide by `10^6` |
| `fundsAccepted` | Total USDC accepted (null if raise not yet closed) |
| `secondsForLaunch` | Duration of the ICO raise window in seconds (604800 = 7 days) |
| `isPermissionLess` | Whether any wallet can contribute without whitelisting |
| `icoReturn` | Return multiple relative to ICO price since launch |

## GET /v1/global-dashboard/completed-launches/info

Returns all completed ICOs with token holder counts and final raise details.

**Parameters:** `limit`, `page`

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/global-dashboard/completed-launches/info?limit=10"
```

<Accordion title="Example Response">
```json
{
  "meta": { "totalItems": 12 },
  "data": [
    {
      "launchAddr": "11111111111111111111111111111111",
      "baseMint": "METAwkXcqyXKy1AtsSgJ8JiUHwGCafnZL38n3vYmeta",
      "title": "MetaDAO",
      "state": "Complete",
      "minimumRaiseAmount": "2200000000000",
      "committedAmount": "8054207616000",
      "fundsAccepted": "8054207616000",
      "tokenSymbol": "META",
      "tokenUsdPrice": "3.0282",
      "holdersCount": "5184",
      "isFeatured": true
    }
  ]
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `holdersCount` | Number of wallets currently holding this token |
| `fundsAccepted` | Final USDC accepted at close of ICO. Divide by `10^6` |
| `isFeatured` | Whether this project is featured on the 01Resolved platform |

## GET /v1/global-dashboard/graveyard-launches

Returns ICOs that completed but whose projects have since been liquidated or wound down.

**Parameters:** `limit`, `page`

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/global-dashboard/graveyard-launches?limit=10"
```

<Accordion title="Example Response">
```json
{
  "meta": { "totalItems": 2 },
  "data": [
    {
      "launchAddr": "8Nmd13rpULJjY7h6oxCfuTWy8WkZxcuDrDWiSdnViVuo",
      "title": "Ranger",
      "tokenSymbol": "RNGR",
      "state": "Complete",
      "reasonStatus": "liquidated",
      "dateEnded": "2026-03-05T16:47:03.000Z",
      "minimumRaiseAmount": "6000000000000",
      "committedAmount": "86398012123099",
      "fundsAccepted": "8000000",
      "fundRaised": "86398012.12",
      "targetRaise": "6000000",
      "icoPrice": "0.8",
      "icoInvestors": "8761",
      "organizationSlug": "ranger"
    }
  ]
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `reasonStatus` | Why the project ended (e.g. `liquidated`) |
| `dateEnded` | Date the project was wound down |
| `fundRaised` | Total USDC raised during the ICO (human-readable) |
| `targetRaise` | The project's stated raise target in USDC |
| `icoInvestors` | Number of wallets that participated in the ICO |
