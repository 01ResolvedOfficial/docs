## GET /v1/dao/account-registry

Returns all wallets tracked for a DAO with balances, labels, and custody type. Powers the **Account Registry** tab.

**Parameters:** `slug` (required)

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/dao/account-registry?slug=solomon"
```

<Accordion title="Example Response">
```json
{
  "data": [
    {
      "address": "Bo24B7DDVtpa9VxZ4LN8FrAT7TM3cgkri41a5GjFg5Dk",
      "name": "Team Performance Package",
      "custodyType": "Program",
      "chain": "Solana",
      "isActive": true,
      "entityType": "DAO",
      "trackingMode": "full",
      "notes": "Team will have a 18-month cliff and unlock tokens in equal tranches at performance milestones."
    }
  ]
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `name` | Labeled wallet name (e.g. `Vault`, `FutarchyAMM`, `DAO Main`) |
| `custodyType` | How the wallet is controlled (e.g. `Multi-sig`, `Program`) |
| `isActive` | Whether this wallet is currently active |
| `entityType` | Classification of the wallet (e.g. `DAO`) |
| `trackingMode` | Level of tracking applied (`full` or `partial`) |
| `notes` | Human-readable notes about the wallet's purpose |

## GET /v1/movement

Returns treasury movements for a project with classification status, category, and counterparty detail. Powers the **Movements** and **Classifications** tabs.

**Parameters:** `project` (required), `limit`, `page`

<Warning>
  This endpoint uses `project=` not `slug=`. Using `slug` returns a 400 error.
</Warning>

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/movement?project=solomon&limit=10"
```

<Accordion title="Example Response">
```json

      "timestamp": "2026-06-04T00:01:25.000Z",
      "from": "DzYtzoNvPbyFCzwZA6cSm9eDEEmxEB9f8AGkJXUXgnSA",
      "fromName": "FutarchyAMM",
      "to": "6awyHMshBGVjJ3ozdSJdyyDE1CTAXUwrpNMaRGMsb4sf",
      "toName": "MetaDAO Multisig",
      "amount": "102.058166",
      "totalValue": 102.058166,
      "tokenSymbol": "USDC",
      "classifiedStatus": "Unclassified",
      "categoryId": null,
      "categoryName": null,

      "proposalTitle": null,
```

</Accordion>

| Field | Description |
|-------|-------------|
| `id` | Numeric movement ID. Used in `/v1/movement/{id}` |
| `fromName` / `toName` | Labeled wallet names for source and destination |
| `classifiedStatus` | Classification state: `Unclassified`, `Classified`, or `Needs Review` |
| `categoryName` / `subCategoryName` | Classification labels once a movement has been reviewed |
| `entity` | Entity type associated with this movement (e.g. `DAO`) |
| `canConfirmed` | Whether this movement is eligible for manual confirmation |

## GET /v1/movement/export/csv

Returns all movements for a project as a CSV file download.

**Parameters:** `project` (required)

<Warning>
  This endpoint uses `project=` not `slug=`. Using `slug` returns a 400 error.
</Warning>

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/movement/export/csv?project=solomon" \
  -o movements.csv
```

Returns a `text/csv` file with the same fields as `/v1/movement`. Use `-o` to save to a file.

## GET /v1/movement/{id}

Returns full detail for a single movement by its numeric ID.

**Parameters:** `id` (path, required)

<Note>
  The `MOV-` prefix shown in the 01Resolved UI is a display convention only. Pass the numeric value after the prefix (e.g. use `19958999`, not `MOV-19958999`).
</Note>

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/movement/19958999"
```

## GET /v1/dao/movements

Returns treasury transactions with labeled source and destination wallets. A simpler alternative to `/v1/movement` that uses `slug` and returns less classification detail.

**Parameters:** `slug` (required), `limit`, `page`

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/dao/movements?slug=solomon&limit=10"
```

<Accordion title="Example Response">
```json
{
  "meta": { "totalItems": 8473 },
  "data": [
    {
      "address": "98SPcyUZ2rqM2dgjCqqSXS4gJrNTLSNUAAVCF38xYj9u",
      "signature": "422ENs8CGqzPqvcvqWsSameFRWVK2nVcv5z377AqFoXoA8A9PTpNjcdtUEnSHCobk5Ms7hBzeHnYQVV4kQieFPjC",
      "timestamp": "2026-05-30T19:18:09.000Z",
      "amount": "100000",
      "value": "99953.15",
      "treasury": { "name": "DAO Main", "address": "98SPcy...", "project": "solomon" },
      "relatedTreasury": { "name": "Expense 1", "address": "BCNsaG...", "project": "solomon" },
      "token": { "symbol": "USDC", "decimals": 6 }
    }
  ]
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `signature` | Solana transaction hash |
| `amount` | Raw token amount. Divide by `10^decimals` for human-readable value |
| `value` | USD value at time of transaction |
| `treasury.name` | Labeled name of the source wallet |
| `relatedTreasury.name` | Labeled name of the destination wallet (if a known DAO wallet) |
| `token.symbol` | Token transferred |
