All endpoints scoped to a project accept a `slug` query parameter. Endpoints scoped to a specific proposal use a `{publicKey}` path parameter — the proposal's onchain public key.

---

## GET /v1/proposal

Returns the project's decision market index: every proposal, with its outcome and the trading statistics shown in the **Proposals** table on a project's page. Start here, then pass a proposal's `publicKey` to the proposal-scoped endpoints below.

**Parameters:** `slug` (required), `limit`, `page`

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/proposal?slug=metadao&limit=10"
```

<Accordion title="Example Response">
```json
{
  "meta": {
    "totalItems": 40,
    "totalPages": 40
  },
  "data": [
    {
      "id": 11839,
      "title": "Treasury Utilization For Ownerships Tokens",
      "publicKey": "Fy5NzNUqnawZuZrXaXgEi1eGPi9gjgwNQ6BgM63mFCLG",
      "creationDate": "2026-09-06T03:38:35.000Z",
      "endDate": "2026-09-09T03:38:35.000Z",
      "status": "resolved",
      "result": "approved",
      "totalTrade": 1192,
      "totalTradeVolume": "143230.157837999970000000",
      "totalUniqueTraders": 8,
      "netPassVolumeTilt": "14.72243940822185384900",
      "netPassTraderTilt": "40.00000000000000000000",
      "passAndFailTWAPSpread": "7.80981931657763091800",
      "twapThreshold": "-3.0000000000000000",
      "twapThresholdMargin": "10.80981931657763091800",
      "twapAndFinalOutcomeSpread": "2.47329739471260735500",
      "organizationSlug": "metadao",
      "tokenSymbol": "META"
    }
  ]
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `publicKey` | Onchain proposal address. Used as the `{publicKey}` path parameter on every proposal-scoped endpoint |
| `creationDate` / `endDate` | When the decision market opened and closed. Shown as **Start Date** and **End Date** |
| `status` | Lifecycle state, e.g. `live` or `resolved` |
| `result` | Final outcome once resolved, e.g. `approved` or `rejected` |
| `totalTradeVolume` / `totalTrade` / `totalUniqueTraders` | USD volume, number of trades, and distinct trading wallets across both markets |
| `netPassVolumeTilt` | Net volume bias toward the pass market in %. Positive = more capital on pass |
| `netPassTraderTilt` | Net trader count bias toward the pass market in % |
| `passAndFailTWAPSpread` | Difference between the pass and fail TWAPs in % |
| `twapThreshold` | Spread required to pass, in %. Negative = a lower bar for team-sponsored proposals |
| `twapThresholdMargin` | How far the spread finished above (positive) or below (negative) the threshold |
| `twapAndFinalOutcomeSpread` | Spread between the TWAP and the final outcome, in % |

## GET /v1/proposal/\{publicKey\}/threshold-chart

Returns TWAP pass-edge data over the TWAP observation window.

**Parameters:** `publicKey` (path, required), `timeInterval` (required: `15m`, `1h`, `4h`, `1d`, `max`)

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/proposal/FG93KeoUdUmBtTcxWhJZicc6ef824qccpFdesbw2RJjM/threshold-chart?timeInterval=1h"
```

<Accordion title="Example Response">
```json
{
  "data": {
    "preTwap": "2026-05-16T03:45:00.000Z",
    "threshold": -3,
    "chartData": [
      { "timestamp": "2026-05-17T03:30:00.000Z", "passEdge": 6.131 },
      { "timestamp": "2026-05-17T03:45:00.000Z", "passEdge": 6.130 }
    ]
  }
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `threshold` | The required TWAP spread to pass (negative = team-sponsored lower bar) |
| `chartData[].passEdge` | TWAP spread at this interval. Formula: `((passTwap - failTwap) / failTwap) × 100 - threshold` |

<Warning>
  `timeInterval` is required. Valid values are `15m`, `1h`, `4h`, `1d`, `max`. Omitting it returns a 400 error.
</Warning>

## GET /v1/trading-activity/\{slug\}

Returns aggregate decision market trading statistics for a project.

**Parameters:** `slug` (path, required)

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/trading-activity/metadao"
```

<Accordion title="Example Response">
```json
{
  "data": {
    "totalVolume": 6397397.76,
    "totalTrades": 134848,
    "totalUniqueTraders": 499
  }
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `totalVolume` | Cumulative USD volume traded across all proposals |
| `totalTrades` | Total individual trades placed |
| `totalUniqueTraders` | Distinct wallet addresses that have traded |
