These endpoints match the **Revenues** and **Expenses** sections of a project's Financials tab. All endpoints accept a `slug` query parameter to identify the project. See [Project Slugs](/guides/project-slugs) for valid values.

---

## GET /v1/dao/revenues

Returns revenue broken down by source and period. The default interval is `month`, and the default date range is the past year.

**Parameters:** `slug` (required), `entityType` (optional), `interval` (`day`, `week`, `month`, `quarter`, or `year`), `startDate`, `endDate`.

`/total-revenue` covers all available history. To reconcile a series to that total, pass an explicit `startDate` before the first revenue observation and an `endDate` covering all recorded revenue, with the same `entityType`. Summing the default past-year series does not produce the all-history total.

```bash
# Full-history comparison; choose dates that cover the project's recorded history.
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/dao/revenues?slug=metadao&interval=month&startDate=2020-01-01&endDate=2026-11-28"
```

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/dao/revenues?slug=metadao"
```

<Accordion title="Example Response">
```json
{
  "data": [
    {
      "period": "2025-12-01",
      "interval": "month",
      "details": [
        { "source": "Protocol fees", "revenue": "2720034.93" }
      ],
      "revenue": "2720034.93"
    }
  ]
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `period` | Start of the requested aggregation period |
| `revenue` | Total USD revenue for this period |
| `details[].source` | Revenue source label (e.g. `Protocol fees`) |
| `details[].revenue` | USD revenue from this source |

## GET /v1/dao/total-revenue

Returns cumulative total revenue in USD.

**Parameters:** `slug` (required)

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/dao/total-revenue?slug=metadao"
```

<Accordion title="Example Response">
```json
{
  "data": {
    "totalRevenue": "3818247"
  }
}
```
</Accordion>

## GET /v1/dao/expenses

Returns monthly expenses broken down by category.

**Parameters:** `slug` (required)

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/dao/expenses?slug=metadao"
```

<Accordion title="Example Response">
```json
{
  "data": [
    {
      "period": "2026-02-01",
      "interval": "month",
      "details": [
        { "source": "Service provider", "expense": "240000" },
        { "source": "Audit / Security", "expense": "0" }
      ],
      "expense": "240000"
    }
  ]
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `period` | Start of the requested aggregation period |
| `expense` | Total USD expenses for this period |
| `details[].source` | Expense category label |
| `details[].expense` | USD amount for this category |
---
