These endpoints power the **Trader Details** page on 01Resolved. Each one looks up a single Solana wallet with the `walletPublicKey` query parameter and covers every ownership coin project unless you pass `slug` where it is supported.

<Warning>
  The parameter is `walletPublicKey`. Using `wallet`, `address`, or `walletAddress` returns a 400 error.
</Warning>

Timestamps on this page are Unix seconds unless shown as ISO 8601 strings.

---

## Keeping holdings current

Holdings and wallet value come from a saved snapshot, not a live read. Every holdings response carries `holdingsLastUpdate`, and the snapshot only changes when a refresh runs.

1. Check `holdingsLastUpdate` in `/v1/trading-activity/special-wallet/holdings/overview`.
2. If it is older than you need, call `POST /v1/trading-activity/special-wallet/holdings/refresh`. It returns a `jobId` straight away.
3. Poll `/v1/trading-activity/special-wallet/holdings/refresh-status?jobId=` until `status` is `completed`, then read holdings again.

A full refresh usually finishes within seconds. This is the same action as the **Update** button on the Trader Details page.

<Note>
  Do not rely on `needsRefresh` to decide when to refresh. It can read `false` on a snapshot that is weeks old. Compare `holdingsLastUpdate` with the current time instead.
</Note>

## GET /v1/trading-activity/special-wallet/overview

Returns the wallet summary shown at the top of the Trader Details page: decision market trading totals, wallet value, wallet age, and snapshot status.

**Parameters:** `walletPublicKey` (required), `slug`

```json
    "walletValue": "212398.8740717089558034399901265994476",

    "refreshLimited": false,
    "refreshRetryAfterSeconds": null,
    "balanceRefreshStatus": "cached",
    "refreshJob": null
  }

```
</Accordion>

| Field | Description |
|-------|-------------|
| `totalVolume` | Total USD this wallet has traded in decision markets |
| `totalTrades` | Number of decision market trades |
| `totalUniqueProposals` | Number of distinct proposals traded |

| `refreshLimited` / `refreshRetryAfterSeconds` | Whether refreshes for this wallet are temporarily limited, and how long to wait before the next one |
| `refreshJob` | The refresh job in progress for this wallet, if any |

## POST /v1/trading-activity/special-wallet/holdings/refresh

Starts a background refresh of the wallet's balances and ownership coin transfer history. Returns immediately with a job to poll.

**Body:** `walletPublicKey` (required)

```bash
curl -X POST -H "x-api-key: YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"walletPublicKey": "JwV3M6PvMykzYeQznSeZA7WdwTvyaXCC4dFWoKvSYZS"}' \
  "https://api.01resolved.com/v1/trading-activity/special-wallet/holdings/refresh"
```

<Accordion title="Example Response (202 Accepted)">
```json
{
  "meta": { "code": 202, "message": "Successful" },
  "data": {
    "jobId": "91f14ed0-bdc9-490f-88bb-dd422f574101",
    "walletPublicKey": "JwV3M6PvMykzYeQznSeZA7WdwTvyaXCC4dFWoKvSYZS",
    "status": "queued",
    "alreadyRunning": false,
    "snapshotRefreshed": false
  }
}
```
</Accordion>

| Field | Description |
|-------|-------------|
| `jobId` | Pass to `/v1/trading-activity/special-wallet/holdings/refresh-status` |
| `status` | `queued` when the job is first accepted |
| `alreadyRunning` | Whether a refresh for this wallet was already in progress |

<Note>
  Refreshes can be rate limited per wallet. If the request is refused with `429`, or `refreshLimited` is `true` on the overview endpoints, wait `refreshRetryAfterSeconds` before trying again.
</Note>

## POST /v1/trading-activity/special-wallet/holdings/project/refresh

Refreshes the balance and transfer history for one ownership coin only. Faster than a full refresh when you only need one token. Holder rank is not recalculated.

**Body:** `walletPublicKey` (required), `tokenAddress` (required, from the holdings list)

```bash
curl -X POST -H "x-api-key: YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"walletPublicKey": "JwV3M6PvMykzYeQznSeZA7WdwTvyaXCC4dFWoKvSYZS", "tokenAddress": "CARSsxWPkpQWvfyRBwfGMGvysJBHdHGfE46X5MNgmeta"}' \
  "https://api.01resolved.com/v1/trading-activity/special-wallet/holdings/project/refresh"
```

Returns a `jobId` in the same shape as the full refresh. Poll it with `refresh-status`.
