## 1. Weekly ecosystem snapshot

Get token price, treasury, NAV, mNAV, premium/discount, and runway for every tracked project in a single call.

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/global-dashboard/projects-launch"
```

Returns every ownership coin with `tokenUsdPrice`, `treasuryValue`, `netAssetValue` (NAV/AS), `mNAV`, `premDisc`, and `monthsOfRunway` for each. `premDisc` is a ratio: multiply by 100 for a percentage. For screens built on these fields, see [NAV/AS Premium & Discount](/guides/nav-premium-discount).

## 2. Monitor all active proposals

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/global-dashboard/projects/decision-markets"
```

Returns every proposal that is `live` (trading) or `initiated` (opened, not yet trading), across all projects. `proposalTwapStatus` shows which way a live market is currently leaning. Pass `proposalPublicKey` to `/v1/proposal/{publicKey}/pass-edge` for the exact margin. For every proposal including resolved ones, use `/v1/global-dashboard/decision-markets`.

## 3. Check if a live proposal is passing

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/proposal/FG93KeoUdUmBtTcxWhJZicc6ef824qccpFdesbw2RJjM/pass-edge"
```

Check `proposalTwapStatus`: `approve`, `reject`, or `pending`. Use `approveRejectTwapDifference` for the current margin.

## 6. Analyze all trades on a decision market

```bash

  "https://api.01resolved.com/v1/proposal/FG93KeoUdUmBtTcxWhJZicc6ef824qccpFdesbw2RJjM/orders?limit=100"

# Trade conviction breakdown
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/proposal/analytics/FG93KeoUdUmBtTcxWhJZicc6ef824qccpFdesbw2RJjM/outcome-strength"

# How conviction changed over time

  "https://api.01resolved.com/v1/proposal/analytics/FG93KeoUdUmBtTcxWhJZicc6ef824qccpFdesbw2RJjM/conviction-chart"
```

## 7. Look up a wallet

```bash
# Ownership coin holdings, with value and holder rank
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/trading-activity/special-wallet/holdings?walletPublicKey=JwV3M6PvMykzYeQznSeZA7WdwTvyaXCC4dFWoKvSYZS"

# Every decision market trade by this wallet
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/trading-activity/special-wallet?walletPublicKey=AWjCySKayUEQFdyBc4zLu7i35BfM3kxAmBxv8qwy1SC5"

# ICOs this wallet took part in
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/trading-activity/special-wallet/ico-participation?walletPublicKey=JwV3M6PvMykzYeQznSeZA7WdwTvyaXCC4dFWoKvSYZS"
```

Holdings come from a saved snapshot. Check `holdingsLastUpdate` and refresh it if needed. See [Wallet Analytics](/api-reference/wallet-analytics#keeping-holdings-current).

## 10. Operating metrics for a project

```bash
curl -H "x-api-key: YOUR_KEY" \
  "https://api.01resolved.com/v1/growth-feed?slug=laso-finance"
```

Daily volume, transactions, and active users, for projects that publish a Growth Feed. Each metric's `semantics` tells you whether daily values can be added together. See [`/v1/growth-feed`](/api-reference/project/overview).
